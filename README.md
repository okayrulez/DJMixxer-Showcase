# DJ Mixxer

A learning-oriented DJ application for beginners, with iOS, web and desktop implementations.

DJ Mixxer creates autonomous mixes and explains how and why transitions happen through the controls on a DJ deck. Making tempo, key and effect choices visible helps users understand mixing and explore their own creative decisions.

My work includes audio mixing, BPM and key analysis, automated transitions, vocal and section layering, and Pioneer DDJ-400 MIDI integration.

**Technologies and areas:** iOS, Python audio processing, web development, MIDI, digital signal processing.

**Website:** https://djmixxer.com
